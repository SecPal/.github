# SecPal

**SecPal – A guard's best friend**

SecPal develops open-source software for physical, organizational and personnel
security. We build for security service providers, professional security
operations and their customers. SecPal aims to connect the operational and
administrative work these teams do every day.

The SecPal product family includes the main product, SecPal, and the planned
specialist products SecPal Assure and SecPal Visit. SecPal is in active
development and remains pre-1.0. See the
[current product direction](https://github.com/SecPal/.github/blob/main/docs/product-positioning.md#current-direction)
and the [public status guide](https://github.com/SecPal/.github/blob/main/docs/public-status-semantics.md)
for how SecPal substantiates capability and availability claims.

Self-hosting and SecPal Managed are intended to offer the same product
functionality. Managed is designed to provide hosting services and
customer-specific orchestration. [ADR-023](https://github.com/SecPal/.github/blob/main/docs/adr/20260824-public-self-hosting-private-managed-operations-adr023.md)
assigns the portable contracts for independent operation to
[public repositories](https://github.com/SecPal/deployment#readme).
