# SecPal organization

This repository holds shared project documentation, GitHub configuration and
community policies for [SecPal](https://github.com/SecPal).

## About SecPal

SecPal develops open-source software for physical, organizational and personnel
security, primarily for security service providers, professional security
operations and their customers. See the [product positioning](docs/product-positioning.md)
for the product family, current direction and hosting model.

## Find your starting point

- [Architecture and repository responsibilities](docs/architecture.md) routes
  to accepted decisions, technical contracts and their implementation owners.
- [Public status semantics](docs/public-status-semantics.md) explains how SecPal
  supports public claims with evidence.
- [Contributing](CONTRIBUTING.md) covers setup, local validation and pull requests.
- [Workspace setup](WORKSPACE_SETUP.md) covers Herdr assignments and private
  previews on `secpal.dev`.
- [GitHub planning and delivery](docs/work-graph-contract.md) defines the native
  issue graph and protected delivery process.
- [Security policy](SECURITY.md) explains how to report a vulnerability privately.

Preflight reports PR size against a 600-line advisory threshold.
See the [contribution guide](CONTRIBUTING.md#pr-size-recommendation)
for reviewability guidance.
