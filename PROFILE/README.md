# SecPal

**SecPal – A guard's best friend**

SecPal is being built as open-source integrated operations software for private security services operating in Germany. Its direction is to connect operational and administrative work where that integration creates genuine domain value, rather than becoming another isolated specialist tool.

By keeping related information and workflows connected, SecPal aims to reduce avoidable repetitive work, duplicate entry, and manual transfer while keeping necessary domain complexity from being pushed onto users. This is intended direction, not a claim that every capability is already implemented.

## Open Source and independent operation

Open Source is fundamental to SecPal. Its software and public technical work can be inspected, contributed to, and improved independently, while self-hosting and independent operation are intentional properties of the public project.

SecPal Managed may keep customer-specific operations and commercial orchestration private. The accepted boundary in [ADR-023](../docs/adr/20260824-public-self-hosting-private-managed-operations-adr023.md) requires those responsibilities not to become hidden technical dependencies for independent operation. Licensing remains repository- and file-specific under the [SecPal Licensing Policy](../docs/licensing-policy.md).

## Current maturity

SecPal is under active development and remains pre-1.0. Architecture, domain modelling, and implementation may change materially during this period. This project-level maturity statement does not claim production readiness or that every intended product domain is being implemented now.
